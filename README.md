# Trust Me, I’m an Ecologist?

Quarto/revealjs workshop slides for a three-hour interactive session on judging ecological evidence.

## Render

```bash
quarto render workshop.qmd
```

Open `workshop.html` in a browser. Press `S` to open the speaker-notes window and `F` for full screen.

Render the participant exercise pack with:

```bash
quarto render exercise-pack.qmd
```

## Workshop structure

- Langhammer et al. opening and closing confidence votes
- Culina et al. findings and five introductory risk-of-bias questions
- Study-design ranking exercise
- ROBITT and target-population reasoning
- Lister–Garcia/Willig rainforest case study
- Break
- Sánchez-Bayo and Wyckhuys insect-review exercise
- Optional Soroye/Guzman bumblebee case
- Evidence tribunal
- Repeat confidence vote and closing reflection

The slide notes contain timings, sources and facilitation prompts. `exercise-pack.qmd` contains participant materials written as concise summaries; distribute the cited papers separately where licensing and access permit.

## Three-hour delivery

Treat the historical-bumblebee slide as optional. The core route is:

1. Opening vote and foundations — 30 minutes
2. Study-design exercise — 25 minutes
3. Luquillo/ROBITT exercise and discussion — 40 minutes
4. Break — 10 minutes
5. Insect-review exercise and synthesis concepts — 40 minutes
6. Evidence tribunal and closing vote — 30 minutes

This leaves approximately five minutes of contingency. If discussion runs long, skip the optional bumblebee case and the moderator-exploration slide rather than shortening the exercises.
